# Usage Guide

How an administrator uses the Hostel Management System day to day. For setup, see [installation.md](installation.md); for the full feature list, see [features.md](features.md).

## Onboarding a tenant

1. Add the tenant through the tenant management section, completing their record as part of onboarding.
2. Open the room allocation grid and pick a room whose status is **Available**.
3. Assign the room; its status changes to **Occupied** so it cannot be double-booked.

## Managing rooms

- The room grid shows every room as **Available**, **Occupied**, or **Maintenance**.
- Set a room to **Maintenance** while it is out of service; it will no longer be offered during allocation.
- Return it to **Available** once it is ready again.

## Billing

- Fees are generated automatically for tenants (see [features.md](features.md)).
- Track payments in the billing section to see which fees are settled and which are outstanding.
- Use the dashboard's analytics and reporting for a high-level view of occupancy and payments.

## Checking out a tenant

1. Settle or record any outstanding fees in the billing section.
2. Complete the checkout in tenant management; this ends the tenant's lifecycle in the system.
3. Confirm the room's status in the allocation grid so it is ready for the next tenant.
